## Project Notes

### [FedFlow](https://github.com/Yashsn1920/FedFlow-)

> A federated learning management platform for coordinating distributed model training across clients without centralizing raw data.

Project creation, client training-package generation, email-based delivery, update validation, trusted-weight aggregation, and round tracking come together in a Flask and PyTorch workflow.

**Python · Flask · PyTorch · TorchVision · Pandas · scikit-learn**

### [FedLung](https://github.com/Yashsn1920/FedLung)

> A privacy-aware research demonstration for binary chest X-ray classification across simulated hospital clients.

Four non-IID clients train locally and share model updates through FedAvg. The project includes preprocessing, evaluation, browser inference, confidence-aware results, and responsible-use documentation.

**Python · PyTorch · ResNet18 · Federated Averaging · Flask · CUDA**

### [Campus Connect](https://github.com/Yashsn1920/CampusZero-)

> A visual-first campus community prototype for events, student activity, announcements, and profiles.

The responsive campus experience pairs plain HTML, CSS, and JavaScript pages with an Express API and local JSON persistence for comments, event activity, registrations, profiles, and announcements.

**HTML · CSS · JavaScript · Node.js · Express**

### [Vehicle Eye](https://github.com/Yashsn1920/Vehicle-eye-)

> A computer-vision application that detects vehicles, estimates their manufacturing decade and dominant color, and flags older models.

The same pipeline is available through a Flask web app, a Tkinter desktop app, and a command-line interface for images, video, and webcam workflows.

**Python · YOLOv8 · PyTorch · ResNet · OpenCV · Flask**

### [Roam India](https://github.com/Yashsn1920/RoamIndia-)

> An AI-assisted travel planner and machine-learning application for trips across India.

Independent XGBoost models estimate flights and hotels, a gradient-boosted model estimates activity costs, and an aggregator combines them with seasonality and booking-window logic. The app also brings together destination guides, day-wise itineraries, recommendations, weather context, and interactive maps.

**Python · XGBoost · scikit-learn · Streamlit · Flask · Plotly · Gemini API**

### [VidyaPath](https://github.com/Yashsn1920/VidhyaPath-)

> An agentic, voice-first learning platform that turns faculty materials into personalized learning experiences.

Faculty materials are assembled into a trusted knowledge base; agents reconcile conflicts, adapt lessons to student needs, predict learning gaps, and support class preparation and placement readiness. The product connects a Next.js frontend to a FastAPI backend and PostgreSQL/Supabase data.

**Python · FastAPI · Next.js · React · TypeScript · PostgreSQL · Supabase**
